# Econome by Pearling

Econome is a focused toolkit of 143 interactive calculators for economics,
neuroeconomics, and behavioral decision science.

## Live site

[earlessentials.github.io/econs-calculator](https://earlessentials.github.io/econs-calculator/)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The app exports as a static site in `out/`. Pushes to `main` automatically
deploy through GitHub Pages.
